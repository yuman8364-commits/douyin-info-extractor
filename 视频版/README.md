# 抖音视频批量提取工具

独立的 Windows 桌面版本，输入多条抖音作品链接后，按顺序批量保存视频文件。

## 功能范围

- 支持粘贴多条作品链接或分享文案，逐条下载视频。
- 只保存视频文件；不导出标题、标签、点赞等作品信息，不下载封面、图集或文案。
- 图文作品会显示为不支持并跳过。
- 提供当前批次状态、单条下载进度、停止任务、保存目录选择和日志查看。
- 使用项目已有的流式视频下载、失败重试、浏览器网络兜底和取消清理能力。
- 输出文件按输入顺序编号；若同名文件已存在，会使用递增后缀，不覆盖原文件。
- 按抖音作品 ID 和标准化链接保存本机提取记录；再次输入已提取作品时会跳过网络下载。
- 如果已提取的视频位于另一个保存目录，会直接从本机复制到当前目录，不会重新下载。
- 首次升级时会从本版本旧运行日志恢复仍在磁盘上的已提取视频记录；已有视频和程序数据不会被清理。
- 剪贴板只在用户明确粘贴时读取；新粘贴中的重复链接会过滤。

默认视频目录为桌面 `抖音视频批量提取`。程序配置、输入缓存、去重记录、浏览器验证状态和运行日志单独保存在程序 `data` 目录，不与完整版本及信息轻量版共用。

## 源码运行

从项目根目录运行：

```powershell
.\.build-venv\Scripts\python.exe .\视频版\video_app.py
```

## 构建并部署

从项目根目录执行：

```powershell
pwsh.exe -File .\构建视频版.ps1
```

构建脚本会生成并部署桌面目录 `抖音视频批量提取工具`。部署只更新本版本的 EXE、`_internal` 和 `VERSION.txt`；已有程序数据及视频输出会保留。
