# 抖音信息提取工具（轻量版）

轻量版只处理公开抖音作品的元数据：

- 标题
- 标签
- 点赞数
- 收藏数
- 评论数
- 作品 ID
- 作者 ID（优先使用公开 `sec_uid`，缺失时回退到 `uid`）

输入链接后，结果按原项目的编号方式增量写入输出目录的 `提取记录.xlsx`。保存采用临时文件校验后原子替换，并按表头更新；原工作簿的其它工作表、额外列和已有内容不会被删除。结果中会明确保存 `作品ID` 和 `作者ID`，方便后续交给 AI 做作品与作者维度的分析。

轻量版不提供视频、图集、封面、文案下载，账号监控、刷新、删除、复制、旧文档导入等完整版本功能也不包含在界面中。

源码模式的构建命令：

```powershell
pwsh -File .\构建轻量版.ps1
```

构建脚本会把程序放到桌面的 `抖音信息提取工具-轻量版` 文件夹；已有该文件夹中的 `data`、日志和输出内容会保留。
